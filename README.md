# 数理统计B 期末复习系统

面向「数理统计B」课程的期末复习 Web 应用：把教材知识点、公式、题库和常见问答组织成一套可交互的复习系统，包含考试倒计时仪表盘、按章/难度/标签筛选的题库、知识讲解和自测页面。

## 功能特性

- **学习仪表盘**：考试倒计时、各章题目数与重要性、难度分布一目了然
- **知识点讲解**：按「章 → 节 → 知识点」三级浏览教材内容
- **公式手册**：课程公式集中查阅
- **题库练习**：支持按章节、难度、标签、来源四种维度筛选
- **核心题**：人工整理的核心题目单独成库
- **常见问答（FAQ）**：χ²/t/F 分布关系、矩估计 vs MLE、置信区间与假设检验等价性、p 值、两类错误、充分统计量、UMVUE、C-R 下界等 10 个高频考点问答
- **数据可维护**：所有内容均为 `data/` 下的 JSON，附数据抽取与修复脚本，方便按新教材迭代

## 技术栈

- 后端：Flask 3 + gunicorn（纯 JSON API）
- 前端：原生 HTML/JS/CSS 模板（`templates/` + `static/`）
- 部署：`render.yaml` 一键部署到 Render

## 快速开始

```bash
pip install -r requirements.txt
python app.py          # 默认 5050 端口，可用 PORT 环境变量覆盖
```

浏览器打开 `http://localhost:5050`。

## 目录结构

```
app.py                  # Flask 应用（页面路由 + API 路由）
data/                   # 全部课程数据（JSON）+ 抽取/修复脚本
templates/              # 页面模板
static/                 # 前端静态资源
render.yaml             # Render 部署配置
```

## 项目亮点

- 课程内容与代码完全分离：复习资料即数据，可复用同一套系统承载其他课程
- 从作品集角度体现「用工程手段解决学习问题」：内容结构化 → JSON 数据管线 → 交互式复习工具
